Как получить APK:
1. Создай аккаунт на github.com и новый репозиторий (Add file -> Upload files).
2. Загрузи ВСЁ содержимое этой папки, включая скрытую папку .github.
3. Открой вкладку Actions, дождись зелёной галочки (3-5 минут).
4. Открой последний запуск, внизу в Artifacts скачай ersin-zangar-apk.
5. Распакуй zip, перекинь app-debug.apk на телефон и установи (разреши установку из неизвестных источников).
